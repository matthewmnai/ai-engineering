# 05 · AI 视觉质检工业项目

> 模块 4 · 模型训练与微调 ｜ 日期：08-31

## 环境标签

🖥️ **仅 AutoDL GPU**（必须有 CUDA 显卡）

## 学习目标

- 完成一个可落地的 AI 视觉质检工业级项目
- 掌握工业质检场景下的数据采集、标注、训练、部署全链路
- 理解缺陷检测的难点：长尾分布、少样本、实时性要求
- 学会工程化封装质检模型并形成可交付的推理服务

## 知识点

| # | 知识点 | 说明 |
|:-:|---|---|
| 1 | 工业质检场景分析 | 表面缺陷、尺寸测量、装配缺失等典型任务 |
| 2 | 缺陷检测方法 | 分类法、检测法（YOLO）、分割法（U-Net） |
| 3 | 少样本与长尾问题 | 数据增强、Focal Loss、过采样策略 |
| 4 | 训练落地流程 | 数据标注 → 划分 → 训练 → 验证 → 迭代 |
| 5 | 模型工程封装 | 推理脚本、批量处理、结果可视化 |
| 6 | 部署与交付 | 模型导出、推理服务化、质检报告生成 |

## 运行说明

```bash
bash setup.sh
python environment/verify_env.py

# 拉取检测 / 分类基座模型
python environment/download_models.py --target autodl 04_training
```

- 质检图像样例放在 `data/`，检测脚本与推理服务位于 `src/`
- 质检结果与可视化输出写入 `outputs/`
